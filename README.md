# Deekshith P: portfolio

Live at **https://deekshith-p.vercel.app**

Personal portfolio of Deekshith P, a data science student, ML researcher and co-founder of [hundrd](https://hundrd.studio/).

- One static HTML file, with no build step and no framework
- Pages: home, about, work, services, contact and play
- Interactive: a gradient-descent chart on the home page and a k-nearest-neighbours playground you train by clicking
- Live projects: [Digit Reader](https://github.com/deeku46/digit-reader), [Bengaluru House Prices](https://github.com/deeku46/bengaluru-house-prices), [Scam SMS Detector](https://github.com/deeku46/scam-sms-detector), [Sales Dashboard](https://github.com/deeku46/sales-dashboard)

Deployed on Vercel from this repo; every push to `main` goes live automatically.
